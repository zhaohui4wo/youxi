# 🚀 字母大冒险 · 打字小游戏

给小朋友的键盘打字练习游戏，纯 HTML / CSS / JavaScript 编写，无需安装任何依赖。

## 🎮 三种模式

| 模式 | 玩法 |
| --- | --- |
| 🔤 字母模式 | 单个字母从天上掉下来，按下对应字母键把它打掉 |
| 🐱 单词模式 | 按顺序拼出完整的英文单词，练习拼读 |
| 🀄 拼音模式 | 看到汉字，敲出它的拼音（不用声调） |

## ✨ 游戏特色

- 三档速度：慢慢来 / 正合适 / 有点快
- 连击加分、每 300 分升一关，速度越来越快
- 3 条命，卡片掉到底部会扣一颗心
- 最高分自动保存在浏览器本地
- Web Audio 现场合成音效，可一键静音
- 空格暂停，切换到其他窗口时自动暂停

## ⌨️ 虚拟键盘与手指指导

- 游戏底部有一条模拟 QWERTY 键盘，按标准盲打指法给每个键标了颜色
- 当前所有卡片的「下一个字母」都会描边高亮，最危险 / 正在输入的那个键会跳动并显示箭头
- 顶部提示会直接写出「左手食指」「右手中指」等手指名称，并显示对应字母
- 左右两只 SVG 手会同步高亮负责按键的那根手指，左手自动镜像
- 键盘支持鼠标和触屏点击，小朋友没有实体键盘也能玩
- 暂停时键盘会自动变暗，避免误触

## 🎨 动态背景与命中特效

- 三种模式各有专属背景：晴空、夕阳、星空
- 背景里有云朵、太阳 / 月亮、彩虹、热气球、小鸟、山丘、花朵、萤火虫、孔明灯和流星
- 每次敲对键都会随机出现星星、火花、彩纸、表情、冲击环等小特效
- 消灭整张卡片时有彩纸爆炸、星光四溅和全屏闪光
- 5 连击会放烟花，升级时还有大型烟花和屏幕震动
- 开始 / 结束界面也有漂浮的云朵、气球和闪光装饰

## 🕹️ 怎么玩

1. 打开页面，选择速度和模式
2. 用键盘敲击掉落卡片上的字母
3. 单词 / 拼音模式需要按顺序拼完整个词
4. 卡片落到最下面的红线会扣一颗心，3 颗心用完游戏结束

## 💻 本地运行

直接用浏览器打开 `index.html` 即可，也可以启动一个本地服务器：

```bash
python3 -m http.server 8123
```

然后访问 <http://localhost:8123>。
